# daev-code

Small addons and fixes for World of Warcraft 1.12 UI addons. Each one is a separate companion
addon, so the addon it extends stays untouched.

| Addon | What it does | Extends |
|---|---|---|
| [PallyPowerNext](https://github.com/daev-code/PallyPowerNext) | One button that casts the next missing blessing from your PallyPower assignments | [PallyPowerTW](https://github.com/ShikawaLePaladin/PallyPowerTW) |
| [pfUIBarOpacity](https://github.com/daev-code/pfUIBarOpacity) | Out-of-combat opacity for pfUI's action bars, per bar | [pfUI](https://github.com/brues-code/pfUI) |
| [RinseCombatOpacity](https://github.com/daev-code/RinseCombatOpacity) | Separate in-combat opacity for Rinse's frame | [Rinse](https://github.com/Otari98/Rinse) |
| [ShaguDPSOpacity](https://github.com/daev-code/ShaguDPSOpacity) | Out-of-combat opacity for ShaguDPS windows | [ShaguDPS](https://github.com/shagu/ShaguDPS) |
| [BagshuiEmptyBag](https://github.com/daev-code/BagshuiEmptyBag) | Toolbar button to empty a bag or compact your bags | [Bagshui](https://github.com/absir/Bagshui) |
| [BagshuiTooltipFix](https://github.com/daev-code/BagshuiTooltipFix) | Stops item tooltips flickering between two items | [Bagshui](https://github.com/absir/Bagshui) |
| [_OWThreatFix](https://github.com/daev-code/_OWThreatFix) | Keeps the window position on login, resizable window, lower OOC opacity | [OWThreat](https://github.com/roby-brok/OWThreat) |

Issues and pull requests are welcome on each repo.
